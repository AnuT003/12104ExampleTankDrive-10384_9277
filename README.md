# Tank Drive Codebase
Welcome! This is a template codebase for a **tank/differential drive** robot. This codebase is aimed towards newer teams.

## Making subsystems
Please read [this documentation page](https://docs.wpilib.org/en/stable/docs/software/commandbased/subsystems.html) on how to create subsystems. There is an example subsystem in [`src/main/java/frc/robot/subsystems/ExampleSubsystem.java`](src/main/java/frc/robot/subsystems/ExampleSubsystem.java) for your reference as well.
